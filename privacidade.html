Política de Privacidade

Esta política se aplica ao Lista Junto no Android e na web. O app permite criar e compartilhar listas de compras sem criar uma conta.

Dados usados pelo app

Listas novas ficam no aparelho até você gerar um convite. Para permitir abrir, editar, sincronizar e excluir listas compartilhadas, o serviço recebe o nome da lista e o conteúdo dos itens, incluindo nome do produto, quantidade, unidade, categoria, preço, moeda da lista, observações e registro da compra. Listas criadas em versões anteriores podem já estar no serviço.

Quando você escolhe ler uma etiqueta, o app solicita acesso à câmera. A imagem é processada em memória no aparelho. Ela não é guardada nem enviada ao serviço. Você escolhe se deseja usar o preço sugerido.

Cada lista tem um código de acesso incluído no link de convite. O app usa esse código nas solicitações ao serviço e guarda o código e a última versão da lista no seu dispositivo para reabertura e consulta sem conexão.

Hospedagem e compartilhamento

O Lista Junto usa o Supabase para operar o serviço de listas e o GitHub Pages para hospedar a versão web. As solicitações ao serviço de listas usam HTTPS.

Ao compartilhar um convite, você escolhe para quem enviar o link. Qualquer pessoa com esse link pode abrir e editar a lista, inclusive alguém a quem ele tenha sido encaminhado. Se você usar outro aplicativo para enviar o convite, o envio também estará sujeito à política desse aplicativo.

Retenção e exclusão

O serviço guarda as listas e seus itens para permitir a consulta e a sincronização. O banco e o serviço de listas não têm um prazo de exclusão automática configurado.

Você pode excluir produtos individualmente. Para excluir a lista inteira, abra a lista, toque na lixeira Excluir lista e confirme. O serviço remove do banco ativo a lista compartilhada, o registro usado para validar o convite e todos os produtos vinculados. O convite deixa de abrir a lista no serviço. Quando o servidor confirma a exclusão, o app tenta remover também a cópia salva no aparelho usado para excluir a lista.

Em Minhas listas, a opção Remover deste aparelho apaga a cópia salva naquele dispositivo. Quem recebeu o convite pode manter uma cópia em outro aparelho e consultá-la sem conexão até removê-la de Minhas listas.

Os logs operacionais de API e banco de dados têm retenção de até 24 horas no plano Free do Supabase. Remover uma lista do banco não apaga esses registros, que expiram conforme a retenção do serviço. O projeto não tem exportação contínua de logs configurada no Supabase.

O projeto não tem backups automáticos nem restauração para um ponto no tempo no Supabase.

Contato de privacidade

Para dúvidas ou pedidos sobre seus dados no Lista Junto, escreva para lindomarsystems@gmail.com. Evite incluir links privados de listas ou dados sensíveis no primeiro contato.

Privacy Policy

This policy applies to Lista Junto on Android and the web. The app lets you create and share shopping lists without creating an account.

Data used by the app

New lists stay on your device until you create an invitation. To let people open, edit, sync and delete shared lists, the service receives the list name and item details, including product name, quantity, unit, category, price, list currency, notes and purchase records. Lists created with an earlier version may already be stored by the service.

When you choose to scan a price tag, the app requests camera access. The image is processed in memory on your device. It is neither stored nor sent to the service. You decide whether to use the suggested price.

Each list has an access code included in the invitation link. The app uses this code when making requests to the service. It stores the code and the last saved version of the list on your device so you can reopen and view it offline.

Hosting and sharing

Lista Junto uses Supabase to operate the list service and GitHub Pages to host the web version. Requests to the list service use HTTPS.

When you share an invitation, you choose who gets the link. Anyone with the link can open and edit the list, including people it was forwarded to. If you share the link using another app, sending it is also subject to that app’s policies.

Retention and deletion

The service stores lists and their items so they can be viewed and synced. The database and list service have no automatic deletion schedule configured.

You can delete products individually. To delete a list, open it, tap the Delete list trash button and confirm. The service removes the shared list, the record used to validate the invitation and all linked products from the active database. The invitation stops opening the list on the service. Once the server confirms the deletion, the app also tries to remove the copy saved on the device that deleted the list.

In My lists, Remove from this device deletes the copy stored on that device. People who received an invitation may keep an offline copy on another device until they remove it from My lists.

Operational API and database logs are retained for up to 24 hours on the Supabase Free plan. Removing a list from the database does not delete these logs. They expire according to the service’s retention settings. The project has no continuous log export configured in Supabase.

The project has no automatic backups or point-in-time recovery in Supabase.

Privacy contact

For questions or requests about your Lista Junto data, email lindomarsystems@gmail.com. Avoid including private list links or sensitive data in your first message.

Política de privacidad

Esta política se aplica a Lista Junto en Android y en la web. La aplicación permite crear y compartir listas de compras sin crear una cuenta.

Datos que usa la aplicación

Las listas nuevas se guardan en el dispositivo hasta que creas una invitación. Para que se puedan abrir, editar, sincronizar y eliminar las listas compartidas, el servicio recibe el nombre de la lista y los datos de los artículos, incluidos el nombre del producto, la cantidad, la unidad, la categoría, el precio, la moneda de la lista, las notas y el registro de compra. Es posible que el servicio ya guarde las listas creadas con versiones anteriores.

Cuando eliges escanear una etiqueta, la aplicación solicita acceso a la cámara. La imagen se procesa en la memoria del dispositivo. No se guarda ni se envía al servicio. Tú decides si quieres usar el precio sugerido.

Cada lista tiene un código de acceso incluido en el enlace de invitación. La aplicación usa el código en las solicitudes al servicio y guarda el código y la última versión de la lista en tu dispositivo para que puedas volver a abrirla y consultarla sin conexión.

Alojamiento y uso compartido

Lista Junto usa Supabase para operar el servicio de listas y GitHub Pages para alojar la versión web. Las solicitudes al servicio de listas usan HTTPS.

Al compartir una invitación, tú eliges a quién enviar el enlace. Cualquier persona con el enlace puede abrir y editar la lista, incluso alguien que lo haya recibido de otra persona. Si usas otra aplicación para enviar el enlace, el envío también está sujeto a la política de esa aplicación.

Conservación y eliminación

El servicio guarda las listas y sus artículos para que puedan consultarse y sincronizarse. La base de datos y el servicio de listas no tienen configurado un plazo de eliminación automática.

Puedes eliminar productos individualmente. Para eliminar la lista completa, ábrela, toca el icono de papelera Eliminar lista y confirma. El servicio elimina de la base de datos activa la lista compartida, el registro que valida la invitación y todos los productos vinculados. El enlace deja de abrir la lista en el servicio. Cuando el servidor confirma la eliminación, la aplicación también intenta borrar la copia guardada en el dispositivo que eliminó la lista.

En Mis listas, la opción Quitar de este dispositivo borra la copia guardada en ese dispositivo. Quien haya recibido la invitación puede conservar una copia en otro dispositivo y consultarla sin conexión hasta que la quite de Mis listas.

Los registros operativos de la API y la base de datos se conservan hasta 24 horas en el plan Free de Supabase. Eliminar una lista de la base de datos no borra estos registros, que caducan según la política de conservación del servicio. El proyecto no tiene configurada la exportación continua de registros en Supabase.

El proyecto no tiene copias de seguridad automáticas ni restauración a un punto en el tiempo en Supabase.

Contacto de privacidad

Para hacer preguntas o solicitudes sobre tus datos en Lista Junto, escribe a lindomarsystems@gmail.com. Evita incluir enlaces privados de listas o datos sensibles en el primer mensaje.
